# 通用笔记整理助手

这个技能帮助用户处理各类笔记相关的事项，包括整理、添加、补充完善和格式化

## 触发条件/使用场景

当用户需要：
- 整理一个或多个原始markdown笔记文档（通常是OCR识别结果）
- 要求整理笔记（非实验笔记）
- 要求将笔记规范化整理 / 生成整理版
- 要求向已有笔记中添加新的内容
- 要求补充完善笔记（补全笔记中略写、缩写的部分）

**注意**：如果发现笔记内容是实验记录相关的内容，请使用 `expnote-organizer` 技能！

## 输入

1. **原始文档**：一个或多个markdown格式的笔记文档
2. **文档类型**：通常是OCR识别的课堂笔记、读书笔记、会议记录、思考记录等
3. **上下文信息**：用户明确指定的操作目标（整理/添加内容/补充完善/规范化整理）

## 功能与引用指引

本 Skill 包含四个核心功能模块，分别定义在 `references/` 目录下的独立文件中。请根据用户的具体需求，查阅对应文件并按其规范执行。

### 1. 初始化并整理笔记

适用于：用户要求从零整理原始OCR笔记，生成规范的笔记文档。

请查阅 `references/ordinote-init-format.md`，其中详细定义了：
- 输出文件命名规则（`笔记整理-{今日日期}.md`，YYMMDD 格式）
- 错别字修正原则与方法（仅修正明显错误，保持原文意思不变）
- 格式整理的分类标准与板块层级（`##` / `###`）
- 公式的 LaTeX 转写规则（`$...$` / `$$...$$`，无法确定原意的保留原样并标注）
- 输出示例
- 内容完整性等注意事项

### 2. 向已有笔记中继续增添内容

适用于：用户要求将新的笔记（子笔记）合并到已有整理好的笔记（母笔记）中。

请查阅 `references/ordinote-add.md`，其中详细定义了：
- 母笔记与子笔记的归类规则（按内容匹配到对应母笔记）
- 复制与格式调整要求（复制子笔记内容并根据母笔记格式调整）
- 用户汇报义务（操作完成后需向用户详细说明修改内容）

### 3. 补充完善笔记（联网搜索）

适用于：用户要求对指定笔记进行补充完善，即识别笔记中所有只是略写、缩写、一笔带过的部分，联网搜索后补全，并用 `<mark>` 高亮标出。

请查阅 `references/ordinote-enrich.md`，其中详细定义了：
- 略写部分的识别标准（缩写、未展开的概念、省略内容、乱码公式等）
- 联网搜索与补充的处理流程
- `<mark>` 高亮规范与示例
- 公式的 LaTeX 转写规范（转写结果 `<mark>` 包裹，原公式保留原样）
- 原有内容零改动等注意事项

### 4. 笔记规范化整理（整理版）

适用于：用户要求将已有笔记重新组织为结构清晰、逻辑完整的整理版笔记（类似实验笔记的 protocol 格式化，但面向通用笔记，格式自适应）。

请查阅 `references/ordinote-normalize.md`，其中详细定义了：
- 输出文件命名规则（`{原文件名称}-整理版.md`）
- 格式确定规则（有以往整理好的笔记则参考其格式；没有或用户没说，则按笔记逻辑内容自行组织）
- 通用模板、板块合并规则与内容处理约束（不得删改已有内容，仅调整顺序和逻辑）
