# 笔记补充完善

## 功能定义

对于用户指定的笔记，识别其中所有**只是略写、缩写、简写或一笔带过**的部分，调用 websearch 或类似工具搜索网络，补充完善这些内容，并将**所有新增的补充内容用** **`<mark style="background-color: lightpink;"></mark>`** **标签高亮标出**。

## 略写部分的识别标准

以下几类内容视为"略写部分"，需要补充完善：

1. **缩写/简写**：专业术语缩写（如理论、方法、模型、机构的缩写）、人名缩写等，需补全全称及简要解释
2. **一笔带过的概念**：只提到名称但未做任何解释的概念、理论、人物、方法、事件等，需补充简要介绍
3. **省略的内容**：如"等"、"……"、"详见某处"等被省略掉的内容，视情况补充
4. **上下文指代**：如"这个理论"、"前面提到的方法"等指代不明的写法，结合笔记内部上下文完善（无需联网）
5. **残缺或乱码的公式**：OCR 产生的乱码、残缺公式，或以纯文本写成的公式（如 `E=mc2`），需转写为规范的 LaTeX（见下文"公式的 LaTeX 转写规范"）

## 处理流程

1. 通读笔记，标记出所有略写部分，形成补充清单
2. 对每个略写部分，判断信息来源：

   - 专业术语、概念、理论、人物等 → **调用 websearch 或类似工具搜索网络**

   - 上下文指代 → 结合笔记内部上下文完善

   - 残缺或乱码的公式 → 结合上下文推断原意，疑似著名公式/定理/模型的，必要时搜索网络确认标准形式后转写
3. 将补充内容写入笔记，**所有新增内容必须用** **`<mark style="background-color: lightpink;"></mark>`** **包裹**
4. 补充内容的写法：

   - 紧跟在对应的略写部分之后，用括号、破折号或独立条目的形式自然衔接

   - **长度适中：以"让读者不看资料也能理解"为目标，避免写成百科全书式的长文**
5. 补充完成后向用户反馈：包括补充了哪些部分、信息来源是什么

## 高亮规范

- 所有通过补充完善新增的内容，必须用 `<mark style="background-color: lightpink;"></mark>` 包裹；原有内容一律不包裹

- **`<mark>`** **默认渲染为黄色荧光，必须始终携带** **`style="background-color: lightpink;"`** **样式属性，使高亮显示为淡粉色**

- 示例：

  - 缩写补全：`GWT<mark style="background-color: lightpink;">（Global Workspace Theory，全局工作空间理论，认为意识来自全局工作空间中的信息广播）</mark>`

  - 概念补充：`- 预测加工<mark style="background-color: lightpink;">：一种认为大脑通过持续生成预测并与感官输入比较来理解世界的理论框架</mark>`

- 若对同一笔记再次运行本功能，已有 `<mark>` 标记的内容不需重复补充，只处理新发现的略写部分

## 公式的 LaTeX 转写规范

- **转写对象**：OCR 产生的乱码、残缺公式，以及以纯文本写成的公式

- **转写规则**：

  - 行内公式使用 `$...$`，独立成行的公式使用 `$$...$$`

  - 结合笔记上下文推断公式的结构和变量含义；若疑似著名的公式、定理或模型，可**调用 websearch 或类似工具搜索**确认其标准形式后再转写

  - 转写结果用 `<mark style="background-color: lightpink;"></mark>` 包裹，**紧跟在原公式之后**以括号形式添加；**原公式保留原样，不删除、不修改**

  - 示例：`E=mc2<mark style="background-color: lightpink;">（$E = mc^2$）</mark>`

- 无法推断原意的乱码公式，不要强行转写，在汇报中向用户反馈即可

## 修改与保存规范

- **在原文件上直接补充，不另存新文件**

- **不得删除、修改任何原有内容**（包括错别字，一律保持原样）

- 本功能只做"补充"这一件事

## 注意事项

1. **原有内容零改动（最重要！！）**：只允许在原有内容附近插入 `<mark style="background-color: lightpink;">` 包裹的新增内容
2. **搜索可靠性**：优先采信权威来源；对搜索结果不确定的内容，宁可不补充，或在补充中使用"据网络资料"等限定语
3. **避免过度补充**：

   - **常见常识、显而易见的日常用语无需补充**

   - 以笔记的主题和深度为判断基准：面向专业的笔记，基础概念可不补；入门性质的笔记则重点补
4. **汇报义务**：完成后向用户详细汇报：补充了哪些部分、信息来源是什么、哪些略写部分未能补充及原因
5. **如果整个笔记没有明显略写部分，向用户如实反馈，不要强行补充**
