# 笔记噪音清理

## 输入

待整理的文件通常是原始文字稿，来源可能是：

- **OCR 识别结果**（课堂笔记OCR识别结果、扫描件OCR识别结果、图片转文字等）：注意形近字混淆、乱码、符号残缺
- **录音转文字内容**（课堂录音、讲座、访谈等）：注意同音字/近音字错误、标点缺失或误断句、口语化表达、专业术语被识别为常用词；英语口音问题（非正宗美式、英式英语口音）

---

## 输出规范

### 文件命名

- 直接在原始文件上修改，不新建文件
- 修改后，将文件命名为：`笔记去噪-{今日日期}.md`
  - 日期格式：YYMMDD（例如：笔记去噪-260829.md）

### 内容处理规则

#### 1. 错字修正

- **原则**：只根据原文语境修改明显的错别字、笔误、OCR识别错误，以及录音转文字产生的同音字/近音字错误
- **方法**：
  - 结合上下文语境判断是否为错字
  - 保持原文意思不变，仅修正明显错误
  - 对于非常不确定的修正，可以添加注释说明

#### 2. 口音修正

- 对于英语录音转文字稿，可能存在讲话人有口音的情况；请根据上下文语境判断是否为口音，修正。
- 对于非常不确定的修正，可以添加注释说明

#### 3. 公式的 LaTeX 转写

- **识别公式**：找出笔记中的数学公式、化学式等公式内容（OCR 结果中常表现为乱码、残缺或纯文本写法）
- **转写为 LaTeX**：
  - 行内公式使用 `$...$`，独立成行的公式使用 `$$...$$`
  - OCR 识别错误的符号（如希腊字母、上下标、运算符被识别错），需结合上下文推断原意后修正
- **无法确定原意的情况**：保留原样，并用 `<mark></mark>` 包裹标注（例如：`<mark>疑似公式，未能转写</mark>`），不得强行猜测转写

#### 4. 去除提取噪音（适用于 PDF/PPT/图片 的提取稿）

- 删去：多余的空格、缩进、项目序号符号（如，`·`，`◇`，`□`等）、换行、连续空行
- **断行修复**：提取工具把一句话切成多行的情况，合并为完整句子
- 页眉页脚、页码等提取噪音直接删除
- **保留源结构线索**：若提取结果中带有幻灯片/页面分隔，用 `---` 分隔线保留，便于后续追溯

示例（提取稿 → 整理后）：

```text
波函数 ψ 满足薛定谔方
程 iℏ∂ψ/∂t =Ĥψ ，其中 Ĥ
为哈密顿算符
```

整理为：

```markdown
波函数 ψ 满足薛定谔方程 $i\hbar\,\partial\psi/\partial t = \hat{H}\psi$，其中 $\hat{H}$ 为哈密顿算符
```

---

## 注意事项

1. **内容完整性（最重要！！）**：
   1. 仅修正笔误、扫描错误，以及修改顺序
   2. **不得额外添加内容！不得私自修改内容！不得删除内容！**
   3. 例外：公式允许按"公式的 LaTeX 转写"规则转写为 LaTeX，但转写必须忠实于原公式的数学含义，不得趁机改变内容
   4. 例外：提取稿中的页眉页脚、页码等提取噪音不属于笔记内容，按"去除提取噪音"规则删除
2. 不需要写页眉页脚等无关信息
