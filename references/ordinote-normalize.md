# 笔记规范化整理

将已有笔记重新组织为结构清晰、逻辑完整的**整理版**笔记

## 格式确定规则（核心，整理前必读）

在开始整理前，先按以下规则确定采用的格式：

### 情形1：参考以往笔记的格式

满足以下任一条件时适用：
- 用户明确指定了以往已整理好的笔记作为格式参考（直接给出文件，或告知所在文件夹）
- 用户提及存在以往整理好的笔记，且能找到

此时：**参考以往笔记的格式整理**，包括其标题层级、板块划分方式、条目写法、命名风格等：
- 本文件下方的通用模板仅供参考，**参考笔记的格式优先级更高**
- **若多份参考笔记之间格式不一致，向用户确认以哪份为准**

### 情形2：自行按照笔记的逻辑内容组织

满足以下任一条件时适用：
- 没有以往的类似笔记
- 用户没有指定、也没有提及参考格式

此时：**自行按照笔记的逻辑内容组织**：
- 分析笔记内容的内在逻辑（主题分类、论证结构、时间顺序、因果关系、流程步骤等，选最贴合笔记内容的一种）
- 按该逻辑划分板块、安排顺序
- 板块格式遵循下方的通用模板

### 补充说明

- 若在同一文件夹中发现明显已整理好的同类笔记（如带有 `-整理版` 后缀的文件），但用户没有指定，可向用户询问是否参考其格式；用户未确认前，按情形2处理

---

## 输出规范

### 文件命名等事项

- 将整理后的笔记**另存为一份 markdown 文件**
- 命名为：`{原文件名称}-整理版.md`
- 新文件保存在同一文件夹下
- **不得在原始文件中直接修改**

### 通用模板（情形2使用；情形1以参考笔记的格式为准）

```markdown
# {原文件名称}-整理版

日期：`{今日日期（如，2026年8月29日）}`

## {主题板块 1}

### {小节 1}

- 内容要点

### {小节 2}

...

---

## {主题板块 2}

...省略

```

组织原则：
- 一级结构（`##`）：笔记的大主题 / 大环节，不同板块之间使用 `---` 分割
- 二级结构（`###`）：主题下的子话题
- 文档开头可添加一段简短的**概述**，用几句话总结本笔记的核心内容（这是唯一允许新增的内容，用于导航；若笔记内容简单可省略）
- 有先后顺序或流程性的内容，使用有序列表（`1. `）编号，允许列表嵌套
- 并列性内容使用无序列表

### 板块合并

- 如果某个主题的内容很少，则将其合并到与其相关的、内容较多的主题板块（`##`）中，作为加粗小标题（如 `**xxx**`）与其他内容区分
- 如果多个主题的内容都很少，则将它们合并成一个板块（`##`），名称根据内容确定

---

## 内容处理规则及注意事项

- **不得删改已有内容，对于已有内容，只允许调整顺序和逻辑关系**（开头概述除外）
- **遇到存在明显笔误、断裂、意义不明的地方，请使用 `<mark></mark>` 标签包裹这些内容，以便于我（用户）审核修改，但不要修改**
- 注意事项：
  - 整理完成后，需向用户汇报：使用了哪种情形的格式（参考了哪份笔记 / 自行组织及所依据的逻辑）、做了哪些结构调整
  - **如果在整理过程中遇到任何问题（如，笔记内容出现了大量重复、某部分明显与其他部分主题不符等等问题），请及时向我反馈**
