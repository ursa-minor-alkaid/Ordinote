# 笔记添加内容

add 功能分为两种模式：

- **无损add**：将子笔记内容全部归入母笔记，母/子内容零删改
- **去重add**：加入前先检查母笔记已有内容，剔除子笔记中与母笔记重复的部分，仅加入新增内容

## 模式选择

- 用户明确指定"无损add"或"去重add"时，按指定模式执行
- 用户只要求 add、未说明使用哪种模式时，**必须先询问用户**，不得自行选择模式后直接执行

## 通用添加规则

两种模式的归类与格式规则相同：

1. 收到需要被添加入已有的笔记的新笔记后（已有笔记记为`母笔记`，新笔记记为`子笔记`），**首先根据待添加笔记的内容，搜索用户给定的本地文件夹，查看已有的笔记 markdown 文件，确定各个部分需要被归类到什么文件中**
   1. `子笔记` 为新的笔记，因此其各个部分可被归类到不同的`母笔记`中，一切以内容为准
2. 将 `子笔记` 的信息复制到`母笔记`后，需**根据`母笔记`原有的格式进行调整**
   1. **不得删改任何 `母笔记` 中的原有内容**，只能进行格式、逻辑、顺序的调整
   2. **不得删改任何 `子笔记` 源文件中的内容**；去重add 中"剔除重复"指不将重复部分复制进母笔记，而非删除子笔记源文件中的内容
3. 若搜索 markdown 文件后未发现合适的`母笔记`，则向用户反馈，反馈内容为：未发现合适`母笔记`的部分、未归类的原因和建议分类
   1. 未发现合适归类的 `子笔记` 部分不得擅自加入 `母笔记` 中

## 无损add

按通用添加规则直接执行：子笔记的全部内容（除无合适母笔记的部分外）均复制归入对应母笔记，不因与母笔记内容重复而省略。

## 去重add

### 阶段一：检查与合并计划（**不修改任何文件**）

1. 按通用添加规则完成子笔记各部分的母笔记归类
2. **通读所有相关母笔记的全部内容**，逐条比对子笔记内容，识别重复部分
   1. 重复以语义为准：表述不同但知识点、论述、数据、公式等实质内容相同的，视为重复
   2. 仅详略或格式不同但实质内容一致的，视为重复；母笔记仅简略提及而子笔记有实质展开的，不视为重复
3. 生成**合并计划**并向用户汇报，计划包括：
   1. 加入清单：子笔记的哪些部分将加入哪个母笔记、归入哪个板块
   2. 去重清单：哪些部分因母笔记已有而不加入，并注明其在对应母笔记中的位置（标题或段落）以便核对
   3. 未归类清单：无合适母笔记的部分、未归类原因与建议分类
4. 此阶段**不得修改、创建任何文件！仅生成合并计划！**

### 阶段二：确认与执行

1. 只有在用户确认合并计划无误后，才执行 add
2. 用户要求调整计划时，按用户意见修订并重新汇报，直至确认
3. 执行时遵循通用添加规则，仅将合并计划中的新增部分加入对应母笔记，格式向母笔记看齐

## 注意事项

- 添加后，需在文件更改之外，向用户详细汇报做了什么修改（哪些板块被归入哪些文件、为什么这样分类）；去重add 还需说明实际剔除了哪些重复内容
- 未添加的部分需要向用户反馈
